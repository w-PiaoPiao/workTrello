# 桌宠看板

Windows / macOS 桌面悬浮小工具：**缩小时是一只卡通桌宠，展开是高颜值 Trello 风格看板**。

## 功能

### 桌宠（折叠态）
- 纯代码绘制的卡通小家伙：漂浮、呼吸、随机歪头/跳跃、眨眼，悬停弹跳
- 右上角角标实时显示"今日聚焦"数量；番茄钟专注时变为倒计时
- 状态联动：专注时打瞌睡、全部完成连跳庆祝、有逾期卡片时难过脸、
  今日截止时紧张脸（冒汗）、截止提醒时跳起示意
- 单击展开看板，拖拽移动，右键菜单（展开 / 今日清单 / 快速添加卡片 /
  暂停动画 / 窗口置顶 / 换皮肤 / 退出），预置皮肤：奶糖 / 雪团 / 可可 / 子夜
- 快速添加 / 批量添加 / 新建列表均为应用风格对话框（不再用系统样式输入框）：
  快速添加输入时实时预览速记解析结果（截止日 / 优先级 / 标签），
  批量添加内嵌列表选择与行数统计、剪贴板多行自动预填
- 今日清单：右键桌宠弹出浮窗，不展开看板即可概览并勾选今日待办

### 看板（展开态）
- 渐变背景 + 半透明圆角列表列，浅色 / 深色双主题
- **多看板**：标题即看板切换器（点开菜单切换 / 新建 / 重命名 / 删除看板，
  至少保留一块；每块看板独立文件存储，互不影响）
- 卡片：标题、备注（支持 Markdown，悬停「👁 预览」渲染）、6 色标签、
  截止日期（自动识别"今天/明天/已逾期"，可清除）、完成勾选、
  优先级（P1/P2/P3，今日聚焦内按优先级+截止日排序）、
  清单（可勾选子任务，卡片上显示 ☑ 进度）、
  附件（文件或直接粘贴剪贴板图片，📎 徽章一键打开）、
  重复周期（每天/每周/工作日/每月/每年/自定义 N 天，完成时自动滚动到
  下一周期并复位，月末/闰日自动钳制）
- 多选批量操作：Ctrl/Cmd+单击多选、Shift+单击范围选中，底部操作栏
  一键批量完成 / 打标签 / 移动 / 归档 / 删除（Esc 取消多选）；右键卡片可"复制卡片"
- 卡片单击编辑、悬停右上角 ✕ 删除；拖拽跨列表移动、列表内重排（QDrag，带插入位置指示线，
  拖到视口边缘自动滚动）
- 键盘操作卡片：方向键在列内/列间移动（无焦点时按方向键从首列开始），
  Return 打开编辑、空格切换完成，`?` 呼出快捷键速查面板
- 鼠标滚轮在看板空白/工具栏区上下滚 = 横向滚动看板（列内仍是纵向滚卡片）
- 悬停卡片可见全部元信息 tooltip（徽章装不下折成 "…" 时信息不丢）
- 列表：双击标题或列头"⋯"菜单重命名、列头"⋯"菜单删除、添加列表
  （添加后新列自动滚入视口）；
  列头箭头按钮折叠/展开列表（状态记忆，重启保持）；
  整列拖拽重排带列间隙插入指示条，拖到列尾空白 = 移到最末
- 右键卡片：开始番茄钟专注（25 分钟，桌宠打瞌睡 + 托盘倒计时，完成 🍅+1，
  累计 5 的倍数有里程碑提示；专注中切换目标需确认）、打开工作目录、
  打开附件、复制卡片、归档
- 今日聚焦：工具栏「今日 {n}」只显示未完成的星标/已逾期/今天截止卡片
  （星标在卡片编辑对话框勾选，右键菜单可一键加/移）
- 日历视图：工具栏 📅 按月历查看各截止日的卡片，点条目打开编辑、
  拖动条目（或从看板拖卡进来）到另一天即改期
- 归档：归档卡片从看板消失，工具栏「归档」可查看与恢复，统计本周完成数
- 导入 / 导出：工具栏「导出」一键生成 Markdown（按列表分组的清单，含清单项）
  或 CSV（含标签/截止日期/优先级/重复周期/番茄数），另有完整备份 .json 导出；
  **导入 Trello 看板导出 JSON / Markdown 任务清单 / 自家备份 JSON 均生成新看板**
  （列表、卡片、标签、清单、截止日、归档状态完整迁移）
- 搜索框：按标题/备注实时过滤卡片（Cmd/Ctrl+F 聚焦，Esc 清空；搜索时统计显示匹配张数）
- 撤销 / 重做：Cmd/Ctrl+Z / Cmd/Ctrl+Shift+Z（Win 亦可用 Ctrl+Y），
  最多 20 步（增删改/移动/批量操作均可）；删除不再弹模态确认（撤销兜底），
  所有操作在看板内弹出轻提示（含撤销快捷键提示，折叠态改走托盘气泡）
- 截止提醒：每分钟检查一次，逐卡提醒（逾期/今天截止/提前 N 天——
  提前量在设置「提醒」中配置 0~3 天），每天每卡每档只提醒一次
- 完成彩蛋：当日完成 3 张 / 5 张有专属鼓励提示
- 顶部统计（总卡片数 / 完成数）、一键切换主题、折叠回桌宠
- 深浅色主题可手动切换；未手动选择时自动跟随系统外观变化
- Esc 键（看板内任意位置）也可折叠
- macOS：看板右下角可拖动调整大小；空看板时显示创建第一列的引导提示

### 通用
- **设置界面**：看板工具栏 ⚙ / 桌宠右键"设置…" / 托盘菜单 / macOS 菜单栏
  （⌘,）打开；分区：外观（主题三选：跟随系统/浅/深）、语言（中文/English）、
  桌宠（待机动画开关、皮肤带色板预览）、窗口（置顶开关）、提醒（截止
  提前量 0~3 天）、数据（目录展示与一键打开）、关于；所有项即时生效，无保存按钮
- **双语界面**：中文 / English 在设置中一键切换、立即生效（全应用静态文案与
  卡片徽章即时刷新，无需重启）；首次启动按系统语言自动选择
- 速记语法与界面语言无关：中文词（明天/周五/3天后/9月20日）与英文词
  （today/tomorrow/in N days/fri/next mon/9/20）恒可用
- 无边框窗口、位置与展开尺寸持久化（QSettings）；窗口置顶默认开启，
  可在桌宠右键菜单或托盘菜单勾选切换
- 应用激活时接管菜单栏：文件（新建卡片/列表/看板、导出、导入 Trello/Markdown、
  归档）、编辑（撤销/重做/复制/粘贴）、视图（今日聚焦/日历视图/快捷键/
  深色主题/窗口置顶/展开收起）均可从顶部菜单操作
- 数据 JSON 原子落盘（防抖 + .tmp + fsync + rename），损坏自动隔离备份，
  启动时若检测到最近好副本（.prev）会询问是否一键恢复
- 系统托盘（显示/隐藏切换、气泡通知、退出）、单实例锁

## 运行

### Windows

```bash
pip install -r requirements.txt
python main.py            # 正常启动
python main.py --debug    # 调试日志
```

或直接双击 `run.bat`。

### macOS

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python main.py            # 正常启动
python main.py --debug    # 调试日志
```

或直接 `./run.sh`（自动优先使用项目内 `.venv`，出错时保留终端窗口看日志）。

## 打包

### Windows

```bash
powershell -ExecutionPolicy Bypass -File tools\build.ps1
```

产物命名：`桌宠看板v{版本号}.exe`（版本号见 `app/config.py` 的 `APP_VERSION`）。

### macOS

```bash
pip install pyinstaller   # 如未安装
bash tools/build.sh
```

产物：`dist/桌宠看板v{版本号}.app`。已设置 `LSUIElement`，运行时不占 Dock，交互经由桌宠本体与菜单栏图标。

## 数据位置

看板数据（多看板工作区）保存在**系统用户数据目录**，与程序文件位置无关，
更新或更换 exe 不会影响数据：

- Windows：`%LOCALAPPDATA%\桌宠看板\`（如 `C:\Users\<你>\AppData\Local\桌宠看板\`）
- macOS：`~/Library/Application Support/桌宠看板/`
- Linux：`~/.local/share/桌宠看板/`

目录结构（v0.2.0 起为多看板工作区；旧版单文件 `board.json` 首次启动自动迁移，
原文件保留作额外备份）：

```
workspace.json       看板索引（列表 + 当前看板）
boards/<id>.json     每块看板一个文件
attachments/<卡id>/  卡片附件文件
board.json           旧版单看板文件（迁移后不再写入，仅留档）
```

可用环境变量 `PET_BOARD_DATA_DIR` 覆盖。窗口大小、主题、置顶等设置存于系统
注册表 / plist（QSettings），互不影响。

### 自动备份与恢复

同一目录下自动维护多层备份，均为带完整旧数据的副本：

- `board.json.prev` —— 最近一次保存前的内容（每次原子写入自动轮转）
- `board.json.snap.<时间戳>.bak` —— 每次正常启动的启动快照（保留最近 10 份）
- `board.json.corrupt.<时间戳>.bak` —— 文件损坏时的隔离副本

- 数据文件损坏/无法解析 → 启动时自动询问是否从最近好副本恢复；
- **看板为空但存在历史快照**（如数据被异常覆盖为空板）→ 启动时询问是否恢复，
  选择"否"会记住选择，直到再次录入过数据才会重新询问；
- 需要手工备份时，复制整个 `桌宠看板` 数据目录即可。

### 重要提醒

- **请只使用最新构建版本的程序，删除/停止使用旧版本 exe**——仓库成形前的旧版
  曾以非原子方式覆盖数据文件（无备份、无恢复提示），是历史数据丢失的原因；
- 保存失败（磁盘满/权限问题）会通过托盘通知提示，不会静默丢写。
